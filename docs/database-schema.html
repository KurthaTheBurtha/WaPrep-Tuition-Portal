Database Table Structure

Tuition management app — Django tuition app

Source of truth: tuition/models.py
User table: tuition_user (custom model, AUTH_USER_MODEL = 'tuition.User')
Default DB (local): SQLite (db.sqlite3) · Staging / production: PostgreSQL
Table naming: Django default — tuition_ + lowercase model name

At a glance — main relationships

Students link to payer users through StudentPayer. Payments tie to students (and payers); bill lines use PaymentBreakdown and PaymentItem.
